# srdblibに属する関数で引数の数が違うものについて

引数の先頭に`*sql.DB`と`*gorp.DbMap`が足りないケース

例

```
			err := srdblib.UpinsEventuser(client, rank, point, eventid, gschedule.Starttime, gschedule.Cmap, id, timestamp)
```
を
```
			err := srdblib.UpinsEventuser(Db, Dbmap, client, rank, point, eventid, gschedule.Starttime, gschedule.Cmap, id, timestamp)
と修正する
```
