
このプログラムはライブ配信サービスのイベントでの各配信者（ルーム）の獲得ポイントを取得しデータベースに保存するためのものです。
このプログラムは以下のような理由により多くの問題を抱えています。

このプログラムを作成したのはまだGoを使い始めてまもないころであり、よく理解できていないところが多かった
また対象となるシステム（API）に対する理解も浅かった
さらにプログラムを作成するにあたり明確なビジョンができていなかった
獲得ポイントの取得はAPIによって行うが、APIは変更されたり追加されたりがなんども繰り返されそのたびに修正を行ってきた

ということで、このプログラムをどうにかしたいので相談する次第です。

なによりもどこでなにをしているかを明確にすることが重要です。パフォーマンスも重要ですが、現時点でも目的を実現するのにじゅうぶんなパフォーマンスを持っています。

全体的に問題は多いのですが、まずScanActive.goにあるGetPointsAll()をどうにかしたいです（もちろんそのためには他のファンクションに対する検討も必要になります）

GetPointsAllは以下のような機能をもちます
1.API（等）を介して定期的に獲得ポイントデータを取得する
2.取得データから配信の継続時間やその配信枠での獲得ポイントを算出する。
3.おなじデータが3つ続いたら真ん中のデータを削除するなどデータの件数を減らす処理を行う
4.データを文字列として整形したものを作りこれもデータベースに保存する

※　2.については、現在は任意の配信者について現在配信中か否かと各配信の開始時刻を知ることのできるテーブルがあり、それを使えばもっとスマートにできると思われます。4.は完全に余計な処理でWebサーバーで行うべきだった（作り始めたころは文字列関連の操作もよくわかっておらず今みたいなことになっている）

まず、フローをすっきりし、それぞれのブロックの役割を明確にし、今後のAPIの変更などにすぐに対応できるようにしておきたいと思います。まずプログラムを見て、どのような方針で進めるべきかを検討してください。
